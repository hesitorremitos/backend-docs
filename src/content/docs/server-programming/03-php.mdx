## Configuracion Inicial

<Steps>
1. Verificar que PHP esta instalado en tu sistema (incluido en Laragon)
2. Configurar un servidor web (Apache/Nginx)
3. Configurar un editor de codigo
4. Crear tu primer archivo PHP
</Steps>

:::note[Estructura Basica]
- Los archivos PHP deben tener la extension `.php`
- El codigo PHP se delimita con `<?php` y `?>`
- Si el archivo solo contiene codigo PHP, se recomienda omitir el cierre `?>`
- Se recomienda usar `declare(strict_types=1);` para mayor seguridad de tipos
:::

## Fundamentos

### Sintaxis Basica
`echo` y `print` son constructores del lenguaje que permiten mostrar una o mas cadenas de texto. La principal diferencia es que `print` solo puede tomar un argumento y siempre devuelve 1.

:::tip
Tambien es posible usar las secuencias de escape `\n` y `\t` para crear saltos de linea y tabulaciones respectivamente.
:::

```php
<?php
declare(strict_types=1);

echo "Hola Mundo";
echo "Hola Mundo\n"; // con salto de linea
```
```php
<?php
declare(strict_types=1);

print("Hola Mundo");
print "Hola Mundo"; // Tambien valido
```

### Variables
Las variables en PHP son contenedores para almacenar informacion. Se identifican siempre con el simbolo `$` seguido del nombre de la variable.

```php
<?php
declare(strict_types=1);

$nombre = "Juan";    // String
$edad = 25;          // Integer
$precio = 19.99;     // Float
$activo = true;      // Boolean
$datos = null;       // Null - Sin valor

// PHP 8.x: Tipado estricto recomendado
function saludar(string $nombre): string {
    return "Hola, $nombre";
}
```

#### Obtener el Tipo de Dato
Para poder obtener el tipo de dato de una variable, se puede usar la funcion `gettype()`. Tambien se pueden usar funciones como `is_string()`, `is_int()`, `is_float()`, para verificar el tipo.

```php
<?php
declare(strict_types=1);

$nombre = "Juan";
$edad = 25;
$precio = 19.99;
$activo = true;
$datos = null;

echo gettype($nombre);  // string
echo gettype($edad);    // integer
echo gettype($precio);  // double
echo gettype($activo);  // boolean
echo gettype($datos);   // NULL
```

### Concatenacion
La concatenacion en PHP se realiza con el operador `.` (punto).

```php
<?php
declare(strict_types=1);

$nombre = "Juan";
$apellido = "Perez";
echo $nombre . " " . $apellido; // Nombre completo
```

Tambien se puede usar la interpolacion de variables dentro de comillas dobles.

```php
<?php
declare(strict_types=1);

$nombre = "Juan";
$apellido = "Perez";
echo "Hola, $nombre $apellido\n"; // Hola, Juan Perez
```

:::caution
Las comillas simples no interpretan variables, por lo que se deben usar comillas dobles para la interpolacion.
```php
echo 'Hola, $nombre'; // Esto NO interpreta las variables
```
:::

### Operadores

#### Operadores Aritmeticos
```php
<?php
declare(strict_types=1);

$suma = 5 + 3;
$resta = 10 - 2;
$multiplicacion = 4 * 2;
$division = 10 / 2;
$modulo = 10 % 3;
```

#### Operadores de Comparacion

| Operador | Descripcion |
|----------|-------------|
| `==`     | Igual a (comparacion flexible) |
| `===`    | Identico a (igual y mismo tipo) |
| `<`      | Menor que |
| `>`      | Mayor que |
| `<=`     | Menor o igual que |
| `>=`     | Mayor o igual que |
| `!=`     | Diferente de |
| `!==`    | No identico |

:::caution[Importante]
Se recomienda usar `===` y `!==` en lugar de `==` y `!=` para evitar problemas de conversion de tipos. Por ejemplo, `"1" == 1` es `true`, pero `"1" === 1` es `false`.
:::

#### Operadores Logicos
| Operador | Descripcion |
|----------|-------------|
| `&&`     | Y logico |
| `\|\|`   | O logico |
| `!`      | No logico |

#### Operadores de Asignacion
```php
<?php
declare(strict_types=1);

$numero = 5;    // Asignacion simple
$numero += 2;   // Suma y asigna
$numero -= 3;   // Resta y asigna
$numero *= 2;   // Multiplica y asigna
$numero /= 2;   // Divide y asigna
$numero %= 2;   // Modulo y asigna
```

## Arrays

Los arrays son estructuras de datos que permiten almacenar multiples valores en una sola variable. PHP soporta arrays indexados y asociativos.

### Arrays Indexados
```php
<?php
declare(strict_types=1);

$frutas = ['manzana', 'pera', 'uva'];
echo $frutas[0]; // Salida: manzana
echo $frutas[1]; // Salida: pera
echo $frutas[2]; // Salida: uva
```

#### Funciones de Arrays

| Funcion | Descripcion |
|---------|-------------|
| `count()` | Devuelve el numero de elementos |
| `array_push()` | Agrega elementos al final |
| `array_pop()` | Elimina el ultimo elemento |
| `array_shift()` | Elimina el primer elemento |
| `array_unshift()` | Agrega elementos al principio |
| `array_merge()` | Combina arrays |
| `array_filter()` | Filtra elementos |
| `array_map()` | Aplica una funcion a cada elemento |

```php
<?php
declare(strict_types=1);

$frutas = ['manzana', 'pera', 'uva'];
$frutas[] = 'naranja';              // Agregar al final
array_push($frutas, 'kiwi');        // Lo mismo
array_pop($frutas);                 // Elimina el ultimo
array_shift($frutas);               // Elimina el primero
```

### Arrays Asociativos
Los arrays asociativos son similares a los diccionarios en otros lenguajes.

```php
<?php
declare(strict_types=1);

$persona = [
    'nombre' => 'Juan',
    'edad' => 25,
    'ciudad' => 'Madrid',
    'activo' => true
];
echo $persona['nombre']; // Salida: Juan
echo $persona['edad'];   // Salida: 25
```

## Funciones

Las funciones son bloques de codigo reutilizables que realizan una tarea especifica.

```php
<?php
declare(strict_types=1);

function calcularPrecioTotal(float $precio, float $impuesto = 0.21): float {
    return $precio * (1 + $impuesto);
}

echo calcularPrecioTotal(100);      // 121
echo calcularPrecioTotal(100, 0.1); // 110
```

:::tip[Funciones modernas PHP 8.0+]
- **Union Types**: `function foo(int|float $numero): void`
- **Named Arguments**: `calcularPrecioTotal(precio: 100, impuesto: 0.1)`
- **Nullsafe Operator**: `$usuario?->getDireccion()?->ciudad`
- **Match Expressions**: Reemplazo mas potente de switch
:::

## Programacion Orientada a Objetos (POO)

La Programacion Orientada a Objetos es un paradigma fundamental en PHP moderno. Desde PHP 5.0 (2004) y especialmente con PHP 7.0+ y 8.0+, el soporte para OOP es robusto y completo.

:::tip[Fuentes]
Basado en [Object Oriented Programming en php.net](https://www.php.net/manual/es/language.oop5.php) y principios SOLID de [PHP: The Right Way](https://phptherightway.com/#object-oriented-programming).
:::

### Clases y Objetos

Una **clase** es una plantilla que define las propiedades y metodos de un objeto. Un **objeto** es una instancia de una clase.

```php
<?php
declare(strict_types=1);

class Persona {
    // Propiedades (atributos)
    public string $nombre;
    public int $edad;
    private ?string $email = null;  // PHP 7.4+: Tipado de propiedades

    // Constructor (PHP 8.0+: Constructor Property Promotion)
    public function __construct(string $nombre, int $edad) {
        $this->nombre = $nombre;
        $this->edad = $edad;
    }

    // Metodos
    public function saludar(): string {
        return "Hola, mi nombre es {$this->nombre}";
    }

    public function setEmail(string $email): void {
        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            throw new InvalidArgumentException('Email invalido');
        }
        $this->email = $email;
    }

    public function getEmail(): ?string {
        return $this->email;
    }
}

// Crear un objeto (instancia)
$persona = new Persona("Juan", 25);
echo $persona->saludar();
$persona->setEmail("juan@example.com");
```

### PHP 8.0+: Constructor Property Promotion

PHP 8.0 introdujo una sintaxis mas concisa para el constructor:

```php
<?php
declare(strict_types=1);

class Producto {
    public function __construct(
        public string $nombre,
        public float $precio,
        private int $stock = 0
    ) {}

    public function estaDisponible(): bool {
        return $this->stock > 0;
    }
}

$producto = new Producto("Laptop", 999.99, 10);
echo $producto->nombre;  // Acceso directo a propiedad publica
```

### Encapsulamiento: Visibilidad

| Modificador | Acceso |
|-------------|--------|
| `public` | Accesible desde cualquier lugar |
| `protected` | Accesible desde la clase y sus hijas |
| `private` | Solo accesible desde la clase que lo define |

```php
<?php
declare(strict_types=1);

class CuentaBancaria {
    private float $saldo = 0;

    public function depositar(float $cantidad): void {
        if ($cantidad <= 0) {
            throw new InvalidArgumentException("La cantidad debe ser positiva");
        }
        $this->saldo += $cantidad;
    }

    public function retirar(float $cantidad): bool {
        if ($cantidad > $this->saldo) {
            return false;
        }
        $this->saldo -= $cantidad;
        return true;
    }

    public function getSaldo(): float {
        return $this->saldo;
    }
}
```

### Herencia

La herencia permite que una clase hija herede propiedades y metodos de una clase padre.

```php
<?php
declare(strict_types=1);

class Animal {
    public function __construct(
        protected string $nombre
    ) {}

    public function hacerSonido(): string {
        return "Sonido generico";
    }
}

class Perro extends Animal {
    public function hacerSonido(): string {
        return "Guau!";
    }

    public function ladrar(): string {
        return "{$this->nombre} dice: Guau!";
    }
}

$perro = new Perro("Firulais");
echo $perro->hacerSonido(); // Guau!
echo $perro->ladrar();      // Firulais dice: Guau!
```

### Interfaces y Clases Abstractas

Las **interfaces** definen un contrato que las clases deben cumplir. Las **clases abstractas** pueden tener metodos implementados y abstractos.

```php
<?php
declare(strict_types=1);

// Interface: solo define metodos, no implementacion
interface Figura {
    public function area(): float;
    public function perimetro(): float;
}

// Clase abstracta: puede tener metodos implementados
abstract class FiguraBase implements Figura {
    public function __construct(
        protected string $color
    ) {}

    public function getColor(): string {
        return $this->color;
    }
}

class Rectangulo extends FiguraBase {
    public function __construct(
        string $color,
        private float $ancho,
        private float $alto
    ) {
        parent::__construct($color);
    }

    public function area(): float {
        return $this->ancho * $this->alto;
    }

    public function perimetro(): float {
        return 2 * ($this->ancho + $this->alto);
    }
}

$rect = new Rectangulo("rojo", 5, 3);
echo $rect->area();      // 15
echo $rect->perimetro(); // 16
```

### Traits

Los **Traits** permiten reutilizar codigo en multiples clases sin usar herencia multiple.

```php
<?php
declare(strict_types=1);

trait Logger {
    public function log(string $mensaje): void {
        echo "[" . date("Y-m-d H:i:s") . "] $mensaje\n";
    }
}

class Usuario {
    use Logger;

    public function __construct(
        public string $nombre
    ) {}

    public function guardar(): void {
        $this->log("Guardando usuario: {$this->nombre}");
    }
}

$usuario = new Usuario("Ana");
$usuario->guardar(); // [2024-...] Guardando usuario: Ana
```

### Namespace y Autoloading

Los **namespaces** organizan el codigo y evitan colisiones de nombres.

```php
<?php
declare(strict_types=1);

namespace App\Models;

class Usuario {
    // ...
}
```

Uso:
```php
<?php
declare(strict_types=1);

require_once 'App/Models/Usuario.php';

use App\Models\Usuario;

$usuario = new Usuario();
```

:::tip[PSR-4 Autoloading]
En proyectos modernos se usa [Composer](https://getcomposer.org/) con PSR-4 para autoloading automatico de clases, siguiendo los estandares de [PHP-FIG](https://www.php-fig.org/psr/psr-4/).
:::

## Manejo de Errores y Excepciones

PHP soporta manejo de excepciones similar a otros lenguajes orientados a objetos.

```php
<?php
declare(strict_types=1);

function dividir(float $a, float $b): float {
    if ($b === 0.0) {
        throw new DivisionByZeroError("No se puede dividir por cero");
    }
    return $a / $b;
}

try {
    $resultado = dividir(10, 0);
} catch (DivisionByZeroError $e) {
    echo "Error: " . $e->getMessage();
} catch (Exception $e) {
    echo "Error general: " . $e->getMessage();
} finally {
    echo "Esto siempre se ejecuta";
}
```
