# Practica 3: API RESTful de Productos con Laravel

<Card title="Objetivo" icon="target">
Desarrollar una API RESTful completa para la gestion de productos utilizando **Laravel**, aplicando los conceptos de **MVC**, **Eloquent ORM**, **migraciones** y **validacion de datos**. Esta practica integra los conocimientos adquiridos en las secciones anteriores del curso.
</Card>

## Requisitos Previos

- PHP 8.1 o superior instalado
- Composer instalado
- Laravel CLI o instalacion via Composer
- Cliente REST (Thunder Client, Postman, o similar)

## Especificacion del Modelo de Datos

Crea una migracion para la tabla `products` con la siguiente estructura:

| Campo | Tipo | Restricciones |
|-------|------|---------------|
| id | unsignedBigInteger | PK, auto-increment |
| name | string(255) | required, unique |
| description | text | nullable |
| price | decimal(10,2) | required, min:0 |
| stock | unsignedInteger | required, default:0 |
| category_id | unsignedBigInteger | FK a categories |
| is_active | boolean | default:true |
| created_at | timestamp | auto |
| updated_at | timestamp | auto |

Ademas, crea la tabla `categories`:

| Campo | Tipo | Restricciones |
|-------|------|---------------|
| id | unsignedBigInteger | PK, auto-increment |
| name | string(100) | required, unique |
| slug | string(100) | required, unique |
| created_at | timestamp | auto |
| updated_at | timestamp | auto |

## Tareas a Realizar

### Parte 1: Configuracion y Modelos

<Steps>
1. Crea un nuevo proyecto Laravel llamado `api-productos`
2. Configura la conexion a la base de datos en `.env`
3. Crea el modelo `Category` con su migracion y seeder
4. Crea el modelo `Product` con su migracion
5. Establece la relacion: **Category hasMany Product**, **Product belongsTo Category**
6. Ejecuta las migraciones
7. Crea factories y seeders para generar datos de prueba (minimo 5 categorias y 20 productos)
</Steps>

### Parte 2: Controladores y API

<Steps>
1. Crea `CategoryController` como API Resource Controller
2. Crea `ProductController` como API Resource Controller
3. Implementa validacion con Form Requests para:
   - StoreProductRequest: valida name, description, price, stock, category_id
   - UpdateProductRequest: valida mismos campos pero opcionales (sometimes)
4. Crea API Resources para transformar la respuesta:
   - `ProductResource`: incluye datos de la categoria relacionada
   - `CategoryResource`: incluye conteo de productos
5. Implementa scopes en Product:
   - `scopeActive()`: productos con is_active = true
   - `scopeInStock()`: productos con stock > 0
   - `scopePriceRange($min, $max)`: productos dentro de rango de precio
</Steps>

### Parte 3: Rutas y Endpoints

Define las siguientes rutas en `routes/api.php`:

```
GET    /api/v1/categories              -> Listar categorias
POST   /api/v1/categories              -> Crear categoria
GET    /api/v1/categories/{id}         -> Ver categoria
PUT    /api/v1/categories/{id}         -> Actualizar categoria
DELETE /api/v1/categories/{id}         -> Eliminar categoria
GET    /api/v1/categories/{id}/products -> Productos de categoria

GET    /api/v1/products                -> Listar productos (con filtros opcionales)
POST   /api/v1/products                -> Crear producto
GET    /api/v1/products/{id}           -> Ver producto
PUT    /api/v1/products/{id}           -> Actualizar producto
DELETE /api/v1/products/{id}           -> Eliminar producto
```

**Parametros de consulta para `/api/v1/products`**:
- `?category={slug}`: Filtrar por categoria
- `?min_price={valor}`: Precio minimo
- `?max_price={valor}`: Precio maximo
- `?search={texto}`: Busqueda por nombre o descripcion
- `?in_stock=true`: Solo productos en stock
- `?sort=price&order=asc`: Ordenamiento

### Parte 4: Testing

<Steps>
1. Crea tests de feature para:
   - Listar productos (verifica estructura JSON y paginacion)
   - Crear producto (verifica validacion y creacion exitosa)
   - Actualizar producto (verifica modificacion de datos)
   - Eliminar producto (verifica eliminacion)
   - Filtrar productos por categoria y rango de precio
2. Ejecuta los tests: `php artisan test`
</Steps>
