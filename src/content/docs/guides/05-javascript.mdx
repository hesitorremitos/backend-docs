# JavaScript Basico

JavaScript es un lenguaje de programacion que se utiliza para crear sitios web interactivos. Sus principales caracteristicas son:
- **Lenguaje de programacion interpretado**: el codigo se ejecuta linea por linea sin necesidad de compilacion previa.
- **Se ejecuta en el navegador**: el codigo JavaScript se ejecuta en el navegador del usuario, permitiendo interacciones dinamicas sin recargar la pagina.
- **Multiplataforma**: funciona en todos los navegadores modernos sin modificaciones.

:::tip
Piensa en JavaScript como el cerebro de tu sitio web, encargado de la interaccion con el usuario, anadiendo dinamismo y vida a la pagina. Es importante entender que JavaScript no puede interactuar directamente con el sistema de archivos del equipo por razones de seguridad.
:::

## Integracion de JavaScript en HTML

Para escribir y ejecutar codigo JavaScript en un archivo HTML, se utiliza la etiqueta `<script>`, que puede colocarse en el `<head>` o al final del `<body>` del archivo HTML.

```html
<script>
    alert("Hola Mundo");
    // alert recibe un String como parametro
    alert("Bienvenido a mi sitio web");
</script>
```

:::caution
El mensaje `Hola Mundo` se muestra una vez la pagina es cargada porque el codigo JavaScript se ejecuta inmediatamente al ser cargado en el archivo HTML. La funcion `alert()` no es recomendada para entornos de produccion ya que interrumpe la experiencia del usuario.
:::

### Script Externo

El codigo JavaScript puede escribirse en un archivo aparte e incluirse con el atributo `src`:

```html
<!-- index.html -->
<script src="scripts/hola.js"></script>
```

```js
// scripts/hola.js
let nombre = "Juan";
let edad = 15;
console.log("Hola, mi nombre es " + nombre + " y tengo " + edad + " años");
```

:::note
Los archivos JavaScript tienen la extension `.js`. Se recomienda colocarlos en la carpeta `scripts/` del proyecto.
:::

## Consola de JavaScript

La consola es una herramienta esencial para la depuracion. Permite ver mensajes de error, advertencias y resultados de expresiones.

```js
let edad = 10;
let nombre = "Juan";
edad = 15;
console.log("Hola, mi nombre es " + nombre + " y tengo " + edad + " años");
```

:::tip
Para abrir la consola en tu navegador, presiona `F12` y selecciona la pestana `Consola`.
:::

## Variables

JavaScript es un lenguaje de **tipado dinamico**, lo que significa que no es necesario especificar el tipo de dato explicitamente. Existen tres formas de declarar variables:

| Palabra clave | Descripcion | Alcance | Recomendacion |
|---------------|-------------|---------|---------------|
| `var` | Forma tradicional | Funcion | Evitar en codigo moderno |
| `let` | Forma moderna | Bloque | **Usar por defecto** |
| `const` | Constante | Bloque | **Usar cuando el valor no cambia** |

```js
let nombre = "Juan";     // Variable mutable
const PI = 3.1416;       // Constante (no se puede reasignar)
// var edad = 25;        // Evitar - tiene alcance de funcion y permite hoisting problematico
```

:::caution
No se puede reasignar una constante. `const PI = 3;` despues de declarada generara un error.
:::

## Tipos de Datos

JavaScript tiene los siguientes tipos de datos primitivos:

| Tipo | Descripcion | Ejemplo |
|------|-------------|---------|
| `string` | Cadena de texto | `"Hola"`, `'Mundo'` |
| `number` | Numero (entero o decimal) | `42`, `3.14` |
| `boolean` | Valor logico | `true`, `false` |
| `null` | Ausencia intencional de valor | `null` |
| `undefined` | Variable declarada sin valor | `undefined` |
| `symbol` | Identificador unico (ES6+) | `Symbol('id')` |
| `bigint` | Numero entero grande (ES2020) | `9007199254740991n` |

```js
let a = 10;
let b = "Hola Mundo";
let c = true;
let d = null;

console.log(typeof a); // "number"
console.log(typeof b); // "string"
console.log(typeof c); // "boolean"
console.log(typeof d); // "object" (quirk historico de JS)
```

:::caution[Coercion de Tipos]
JavaScript realiza conversiones automaticas que pueden generar resultados inesperados:
```js
let a = '1';
let b = 7;
console.log(a + b); // "17" (concatenacion, no suma)
console.log(a - b); // -6 (resta numerica)
```
:::

## Operadores

### Aritmeticos

| Operador | Descripcion | Ejemplo | Resultado |
|----------|-------------|---------|-----------|
| `+` | Suma | `5 + 3` | `8` |
| `-` | Resta | `5 - 3` | `2` |
| `*` | Multiplicacion | `5 * 3` | `15` |
| `/` | Division | `15 / 3` | `5` |
| `%` | Modulo (resto) | `10 % 3` | `1` |
| `**` | Potencia (ES2016) | `2 ** 3` | `8` |
| `++` | Incremento | `a++` | Incrementa en 1 |
| `--` | Decremento | `a--` | Decrementa en 1 |

### Comparacion

| Operador | Descripcion | Uso Recomendado |
|----------|-------------|-----------------|
| `===` | Igualdad estricta (valor y tipo) | **Siempre preferir** |
| `!==` | Desigualdad estricta | **Siempre preferir** |
| `==` | Igualdad flexible (coercion) | Evitar |
| `!=` | Desigualdad flexible | Evitar |
| `>`, `<` | Mayor que, Menor que | - |
| `>=`, `<=` | Mayor o igual, Menor o igual | - |

:::caution[=== vs ==]
El operador `===` compara tanto el valor como el tipo de dato. El operador `==` realiza coercion de tipos antes de comparar, lo que puede generar resultados inesperados:
```js
console.log(5 == "5");   // true (coercion)
console.log(5 === "5");  // false (tipos diferentes)
console.log(0 == false); // true (coercion)
console.log(0 === false);// false (tipos diferentes)
```
:::

### Logicos

| Operador | Descripcion | Ejemplo |
|----------|-------------|---------|
| `&&` | AND logico | `true && false` → `false` |
| `\|\|` | OR logico | `true \|\| false` → `true` |
| `!` | NOT logico | `!true` → `false` |

## Estructuras de Control

### Condicionales

```js
let edad = 20;

if (edad >= 18) {
    console.log("Eres mayor de edad");
} else if (edad >= 13) {
    console.log("Eres adolescente");
} else {
    console.log("Eres menor de edad");
}

// Operador ternario (forma concisa)
let mensaje = edad >= 18 ? "Mayor de edad" : "Menor de edad";
```

### Bucles

```js
// For
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// While
let contador = 0;
while (contador < 5) {
    console.log(contador);
    contador++;
}

// For...of (iterar arrays)
let frutas = ["manzana", "pera", "uva"];
for (let fruta of frutas) {
    console.log(fruta);
}

// For...in (iterar propiedades de objetos)
let persona = { nombre: "Juan", edad: 25 };
for (let clave in persona) {
    console.log(clave + ": " + persona[clave]);
}
```

## Funciones

### Declaracion de Funciones

```js
// Declaracion tradicional
function saludar(nombre) {
    return "Hola, " + nombre;
}

// Expresion de funcion (anonima)
const despedir = function(nombre) {
    return "Adios, " + nombre;
};

// Arrow function (ES6+) - forma moderna recomendada
const saludar = (nombre) => {
    return "Hola, " + nombre;
};

// Arrow function con return implicito (una sola expresion)
const saludar = nombre => "Hola, " + nombre;

// Arrow function con parametros multiples
const sumar = (a, b) => a + b;
```

:::tip[Arrow Functions]
Las arrow functions (`=>`) son la forma moderna y recomendada en JavaScript. Tienen ventajas sobre las funciones tradicionales:
- Sintaxis mas concisa
- No tienen su propio `this` (heredan el del contexto padre)
- No se pueden usar como constructores
- Ideales para callbacks y funciones de una sola expresion
:::

## Objetos

Los objetos son estructuras de datos que almacenan pares clave-valor:

```js
const persona = {
    nombre: "Juan",
    apellido: "Perez",
    edad: 25,
    casado: false,
    direccion: {
        calle: "Av. Principal",
        numero: 123,
        ciudad: "Quito"
    },
    saludar() {
        return `Hola, mi nombre es ${this.nombre} ${this.apellido}`;
    }
};

// Acceso a propiedades
console.log(persona.nombre);           // "Juan"
console.log(persona["apellido"]);      // "Perez"
console.log(persona.direccion.calle);  // "Av. Principal"
console.log(persona.saludar());        // "Hola, mi nombre es Juan Perez"

// Desestructuracion (ES6+)
const { nombre, edad } = persona;
console.log(nombre); // "Juan"
```

## Arrays

Los arrays son colecciones ordenadas de elementos:

```js
let frutas = ["manzana", "pera", "uva"];
let numeros = [1, 2, 3, 4, 5];

// Metodos comunes
frutas.push("naranja");           // Agregar al final
frutas.pop();                      // Eliminar el ultimo
frutas.unshift("fresa");          // Agregar al inicio
frutas.indexOf("pera");           // Buscar indice
frutas.includes("uva");           // Verificar existencia

// Metodos funcionales (programacion funcional)
numeros.map(n => n * 2);          // [2, 4, 6, 8, 10]
numeros.filter(n => n > 2);       // [3, 4, 5]
numeros.reduce((a, b) => a + b, 0); // 15 (suma total)
numeros.find(n => n > 3);         // 4 (primer elemento que cumple)
```

## Manipulacion del DOM

El DOM (Document Object Model) es la representacion en memoria de la estructura HTML de la pagina.

### Seleccion de Elementos

```js
// Seleccion por ID
const boton = document.querySelector("#btn-form");

// Seleccion por clase
const items = document.querySelectorAll(".item");

// Seleccion por etiqueta
const parrafos = document.querySelectorAll("p");
```

### Modificacion de Elementos

```js
const boton = document.querySelector("#btn-form");

// Modificar texto
boton.textContent = "Enviar";

// Modificar estilos
boton.style.backgroundColor = "blue";
boton.style.color = "white";

// Modificar atributos
boton.setAttribute("disabled", "true");
boton.removeAttribute("disabled");

// Agregar/eliminar clases
boton.classList.add("activo");
boton.classList.remove("inactivo");
boton.classList.toggle("visible");
```

## Manejo de Eventos

Los eventos permiten responder a acciones del usuario. La forma moderna y recomendada es usando `addEventListener`:

```js
const boton = document.querySelector("#btn-form");

// Forma moderna (recomendada)
boton.addEventListener("click", (evento) => {
    evento.preventDefault(); // Evitar comportamiento por defecto
    console.log("Boton clickeado");
});

// Evento de envio de formulario
const formulario = document.querySelector("form");
formulario.addEventListener("submit", (evento) => {
    evento.preventDefault();
    // Validar y enviar datos
});
```

### Eventos Comunes

| Evento | Descripcion | Elementos |
|--------|-------------|-----------|
| `click` | Clic del raton | Todos |
| `submit` | Envio de formulario | `<form>` |
| `input` | Cambio en un input | `<input>`, `<textarea>` |
| `change` | Cambio confirmado | `<input>`, `<select>` |
| `keydown` | Tecla presionada | Elementos con foco |
| `load` | Carga completada | `window` |
| `DOMContentLoaded` | DOM listo | `document` |

:::tip[DOMContentLoaded vs load]
- `DOMContentLoaded`: Se ejecuta cuando el DOM esta listo (no espera imagenes/CSS). Ideal para scripts que manipulan el DOM.
- `load`: Se ejecuta cuando toda la pagina (incluyendo imagenes) esta cargada. Usar solo cuando se necesite todo el contenido.
:::

## Ejercicio Practico: Validacion de Formulario

Implementa un formulario con validacion completa usando los conceptos aprendidos:

```html
<form action="#" id="registro-form">
    <div>
        <label for="email">Correo:</label>
        <input type="text" id="email" placeholder="Ingrese su correo">
    </div>
    <div>
        <label for="password">Contrasena:</label>
        <input type="password" id="password" placeholder="Minimo 6 caracteres">
    </div>
    <button type="submit">Registrar</button>
</form>
```

```js
document.addEventListener("DOMContentLoaded", () => {
    const form = document.querySelector("#registro-form");
    const emailInput = document.querySelector("#email");
    const passwordInput = document.querySelector("#password");

    form.addEventListener("submit", (evento) => {
        evento.preventDefault();

        let errores = [];

        // Validar email
        if (emailInput.value.trim() === "") {
            errores.push("El correo no puede estar vacio");
        } else if (!emailInput.value.includes("@")) {
            errores.push("El correo debe contener @");
        }

        // Validar password
        if (passwordInput.value.length < 6) {
            errores.push("La contrasena debe tener al menos 6 caracteres");
        }

        if (errores.length > 0) {
            console.error("Errores:", errores);
        } else {
            console.log("Registro exitoso!");
        }
    });
});
```
