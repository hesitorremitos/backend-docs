# Proyectos para Practicar Laravel

A continuacion se presentan proyectos propuestos para practicar los conceptos aprendidos en el curso. Estos proyectos cubren desde nivel basico hasta avanzado, permitiendo aplicar progresivamente los conocimientos de MVC, Eloquent, Blade, Middleware y API REST.

## 1. Inventario de Libreria (Basico)

Un sistema simple para gestionar libros y categorias.

<Steps>
1. Configurar el proyecto con autenticacion (Breeze o Jetstream)
2. Crear modelo `Category` con nombre y descripcion
3. Crear modelo `Book` con titulo, autor, ISBN, precio, stock y categoria
4. Implementar CRUD completo para ambos modelos con validacion
5. Usar Blade para las vistas con layout compartido
6. Implementar busqueda por titulo o autor
</Steps>

**Habilidades practicadas**: CRUD, validacion, Blade, relaciones, busqueda

## 2. API REST de una Tienda Online (Intermedio)

Desarrollar una API completa para gestion de productos con autenticacion.

### Requisitos:

| Entidad | Campos | Relaciones |
|---------|--------|------------|
| Product | name, description, price, stock, image_url, is_active | belongsTo Category |
| Category | name, slug, description | hasMany Product |
| Order | user_id, total, status, shipping_address | belongsTo User, hasMany OrderItem |
| OrderItem | order_id, product_id, quantity, price | belongsTo Order, belongsTo Product |

### Funcionalidades:

<Steps>
1. Autenticacion completa con Sanctum (registro, login, logout)
2. CRUD de productos y categorias
3. Carrito de compras (sesion o base de datos)
4. Proceso de checkout y creacion de ordenes
5. Filtrado de productos por categoria, rango de precio y disponibilidad
6. Paginacion y ordenamiento de resultados
7. API Resources para transformar respuestas
8. Form Requests para validacion
9. Policies para autorizacion (solo admin puede crear/editar productos)
10. Testing de endpoints con PHPUnit
</Steps>

## 3. Blog con Panel de Administracion (Intermedio)

Sistema de blog con roles de usuario y panel administrativo.

### Funcionalidades:

<Steps>
1. **Autenticacion y Autorizacion**:
   - Registro y login de usuarios
   - Roles: Administrador, Editor, Lector
   - Middleware para proteccion de rutas segun rol

2. **Gestion de Posts**:
   - CRUD completo de publicaciones
   - Editor de texto enriquecido (Markdown o WYSIWYG)
   - Estados: Borrador, Publicado, Archivado
   - Slug automatico para URLs amigables

3. **Sistema de Comentarios**:
   - Comentarios anidados (respuestas)
   - Moderacion de comentarios

4. **Categorias y Etiquetas**:
   - Relaciones polimorficas o muchos a muchos
   - Nube de etiquetas

5. **Panel de Administracion**:
   - Dashboard con estadisticas (posts, comentarios, usuarios)
   - Gestion de usuarios
   - Moderacion de comentarios
</Steps>

## 4. API de Gestion de Tareas - Kanban (Avanzado)

Sistema de gestion de proyectos tipo Trello con API completa.

### Modelos:

| Modelo | Descripcion |
|--------|-------------|
| `Workspace` | Espacio de trabajo |
| `Board` | Tablero dentro de un workspace |
| `Column` | Columna del tablero (To Do, Doing, Done) |
| `Task` | Tarea dentro de una columna |
| `Label` | Etiqueta de color para tareas |
| `Comment` | Comentario en una tarea |

### Funcionalidades Avanzadas:

<Steps>
1. **Drag & Drop**: Reordenamiento de tareas entre columnas via API
2. **WebSockets**: Actualizacion en tiempo real con Laravel Echo + Pusher
3. **Archivos Adjuntos**: Subida de archivos a S3 o almacenamiento local
4. **Notificaciones**: Sistema de notificaciones en app y por email
5. **Busqueda Full-Text**: Busqueda avanzada con Laravel Scout
6. **Exportacion**: Exportar tableros a CSV o PDF
</Steps>

## Recomendaciones para todos los Proyectos

<Card title="Buenas Practicas" icon="approve-check">
- Usa siempre `declare(strict_types=1);` en archivos PHP
- Implementa validacion con Form Requests
- Usa API Resources para transformar respuestas
- Escribe tests para tus endpoints y modelos
- Documenta tu API con herramientas como Scribe o Swagger
- Sigue los estandares PSR para el estilo de codigo
- Usa migraciones y seeders para la base de datos
- Implementa manejo de errores con try/catch
</Card>
