Todos los comandos de Laravel se ejecutan a través de **Artisan**, la interfaz de línea de comandos integrada. Todos comienzan con `php artisan`.

## Requerimientos

- PHP instalado y en el PATH
- Composer instalado

```bash
php --version
composer --version
```

## Crear un proyecto Laravel

```bash
composer create-project laravel/laravel nombre-proyecto
```

El proyecto se creará en la ruta actual de la terminal.

## Comandos esenciales

### Servidor de desarrollo

```bash
"php artisan serve"
```

:::tip
Mantén la ventana abierta. Cuando se cierre, el servidor se detiene.
:::

### Habilitar API

En versiones determinadas la API no viene habilitada por defecto:

```bash
php artisan install:api
```

Si el archivo `routes/api.php` ya existe, no es necesario ejecutar el comando.

### Crear migración (tabla)

```bash
php artisan make:migration create_usuarios_table
```

El nombre de la tabla debe ser en **plural** con terminación en "s".

### Crear modelo

```bash
php artisan make:model Producto
```

El modelo debe estar en **singular**. Para crear modelo con migración y controlador:

```bash
php artisan make:model Producto -m
```

### Crear controlador

```bash
php artisan make:controller ProductoController
```

Para un controlador API con métodos CRUD predefinidos:

```bash
php artisan make:controller ProductoController --api
```

### Crear múltiples recursos de una vez

```bash
"php artisan make:model Producto -mcr --api"
```

| Flag | Qué hace |
|------|----------|
| `-m` | Crea la migración (tabla con terminación 's') |
| `-c` | Crea el controlador correspondiente |
| `-r` | Añade métodos CRUD predefinidos al controlador |
| `--api` | Los recursos se crean para una API (sin vistas HTML) |

:::caution
Laravel pluraliza automáticamente el nombre del modelo para la tabla. Si defines "Facultad", creará "facultads". Si necesitas un nombre personalizado, define `$table` en el modelo.
:::

### Ejecutar migraciones

```bash
php artisan migrate
```

Para reiniciar desde cero:

```bash
php artisan migrate:fresh
```

Consulta la [documentación de migraciones](https://laravel.com/docs/11.x/migrations#artisan-commands) para más comandos como `rollback`, `refresh` y `status`.

### Listar rutas

```bash
php artisan route:list
```

### Ver todos los comandos disponibles

```bash
php artisan list
```
