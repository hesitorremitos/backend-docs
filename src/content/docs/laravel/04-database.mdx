Laravel incluye un sistema de [migraciones](https://laravel.com/docs/11.x/migrations) que funciona como **control de versiones para tu base de datos**. Te permite definir la estructura de tablas con PHP, compartirla entre desarrolladores y revertir cambios de forma controlada.

:::tip[Recuerda]
Toda migración debe poder revertirse en el método `down()`. Esto garantiza que puedas deshacer cambios sin riesgo.
:::

## Ejemplo rápido

Crea una migración y define la tabla:

```bash
php artisan make:migration create_users_table
```

Esto genera un archivo en `database/migrations/`. Define la estructura en el método `up`:

```php title="database/migrations/xxxx_create_users_table.php"
Schema::create('users', function (Blueprint $table) {
    "table->id();"
    $table->string('name');
    $table->string('email')->unique();
    $table->timestamps();
});
```

```bash
php artisan migrate
```

## Tipos de columna más usados

```php title="database/migrations/xxxx_create_products_table.php"
Schema::create('products', function (Blueprint $table) {
    $table->id();                          // Clave primaria autoincremental
    $table->string('name');                // VARCHAR(255)
    $table->string('sku')->unique();       // Con índice único
    $table->integer('stock');              // entero
    $table->boolean('is_active');          // true/false
    $table->decimal('price', 8, 2);        // Decimal con precisión
    $table->text('description');           // TEXT (largo)
    "table->foreignId('user_id')->constrained()->onDelete('cascade');"
    $table->timestamps();                  // created_at + updated_at
    "$table->softDeletes();"
});
```

:::info[¿Qué genera esto?]
| Columna | Tipo en BD | Uso |
|---|---|---|
| `id` | `BIGINT UNSIGNED AUTO_INCREMENT` | Identificador único |
| `name` | `VARCHAR(255)` | Nombre |
| `sku` | `VARCHAR(255) UNIQUE` | Código único |
| `price` | `DECIMAL(8,2)` | Precio con 2 decimales |
| `user_id` | `BIGINT UNSIGNED` | FK → `users.id` |
| `deleted_at` | `TIMESTAMP NULL` | Borrado lógico |
:::

Otros tipos útiles para cuando los necesites:

```php
$table->date('birthday');              // YYYY-MM-DD
$table->dateTime('published_at');      // Fecha y hora
$table->time('sunrise');               // Solo hora
$table->year('graduation_year');       // Solo año
$table->enum('status', ['active', 'inactive']); // Valores fijos
$table->json('options');               // JSON
$table->uuid('identifier');            // UUID v4
```

Para la [lista completa de tipos de columna](https://laravel.com/docs/11.x/migrations#available-column-types) disponibles, consulta la documentación oficial.

:::note[String con longitud personalizada]
Por defecto, `$table->string('name')` crea un `VARCHAR(255)`. Si necesitas menos caracteres:
```php
$table->string('country_code', 3);  // VARCHAR(3)
```
:::

## Modificadores de columna

Los [modificadores](https://laravel.com/docs/11.x/migrations#column-modifiers) se encadenan al final de la definición del tipo:

```php title="database/migrations/xxxx_create_posts_table.php"
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    "$table->string('subtitle')->nullable();"           // Permite NULL
    "$table->boolean('published')->default(false);"     // Valor por defecto
    "$table->string('slug')->unique();"                 // Índice único
    $table->decimal('revenue', 12, 2)->comment('Ingresos en local');
    $table->string('phone')->after('email');            // Posición (MySQL)
    $table->timestamps();
});
```

Puedes combinar modificadores:

```php
$table->string('email')
      ->unique()
      ->nullable()
      ->comment('Correo de contacto');
```

## Creación y actualización de tablas

**Crear tabla** con el método [`create`](https://laravel.com/docs/11.x/migrations#creating-tables):

```php
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->text('content');
    $table->timestamps();
});
```

**Actualizar tabla existente** (agregar columna) con el método [`table`](https://laravel.com/docs/11.x/migrations#modifying-tables):

```php
Schema::table('users', function (Blueprint $table) {
    $table->string('phone')->nullable();
});
```

**Eliminar columna:**

```php
Schema::table('users', function (Blueprint $table) {
    $table->dropColumn('phone');
});
```

**Renombrar tabla:**

```php
Schema::rename('customers', 'clients');
```

:::caution[Modificar columnas existentes]
Para cambiar el tipo de una columna o renombrar columnas, necesitas instalar `doctrine/dbal`:
```bash
composer require doctrine/dbal
```
Consulta la [documentación sobre modificación de columnas](https://laravel.com/docs/11.x/migrations#modifying-columns) para más detalles.
:::

**Eliminar tabla:**

```php
Schema::dropIfExists('posts');
```

## Índices

```php title="database/migrations/xxxx_add_indexes_to_users_table.php"
Schema::table('users', function (Blueprint $table) {
    $table->index('email');                          // Índice simple
    $table->index(['last_name', 'first_name']);      // Índice compuesto
    $table->unique('dni');                           // Índice único
    $table->fullText('biography');                   // Texto completo
});
```

Consulta la [documentación sobre índices](https://laravel.com/docs/11.x/migrations#indexes) para crear, nombrar e eliminar índices de forma manual.

## Claves foráneas

Laravel ofrece una sintaxis moderna para definir [claves foráneas](https://laravel.com/docs/11.x/migrations#foreign-key-constraints):

```php
// Forma moderna (recomendada)
$table->foreignId('user_id')->constrained()->onDelete('cascade');

// Forma clásica
$table->unsignedBigInteger('user_id');
$table->foreign('user_id')->references('id')->on('users')->onDelete('cascade');
```

El método `constrained()` usa convenciones para determinar la tabla y columna referenciada automáticamente.

## Comandos de migración

| Comando | Descripción |
|---|---|
| `php artisan migrate` | Ejecuta migraciones pendientes |
| `php artisan migrate:rollback` | Revierte la última migración |
| `php artisan migrate:rollback --step=3` | Revierte las últimas 3 |
| `php artisan migrate:reset` | Revierte todas |
| `php artisan migrate:refresh` | Revierte y vuelve a ejecutar |
| `php artisan migrate:fresh` | Elimina tablas y re-ejecuta |
| `php artisan migrate:fresh --seed` | Fresh + ejecuta seeders |
| `php artisan migrate:status` | Muestra estado de cada migración |

Consulta la [documentación completa de comandos de migración](https://laravel.com/docs/11.x/migrations#artisan-commands).

## Convención de nombres

```bash
php artisan make:migration create_orders_table        # Crear tabla
php artisan make:migration add_status_to_orders_table  # Agregar columna
php artisan make:migration rename_total_to_amount      # Renombrar columna
php artisan make:migration remove_discount_from_orders # Eliminar columna
```

## Ejercicio

<Card title=":badge[Actividad]{variant=caution} Ejercicio: Tablas categories y products">

Crea migraciones para `categories` y `products` con relación FK y cascade.

**Tabla `categories`:** `id`, `name`

**Tabla `products`:** `id`, `name`, `price` (decimal), `description` (nullable), `stock` (integer), `category_id` (FK → cascade)

<details>
<summary>Ver solución</summary>

```bash
php artisan make:migration create_categories_table
php artisan make:migration create_products_table
```

```php title="database/migrations/xxxx_create_categories_table.php"
Schema::create('categories', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->timestamps();
});
```

```php title="database/migrations/xxxx_create_products_table.php"
Schema::create('products', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->decimal('price', 10, 2);
    $table->text('description')->nullable();
    $table->integer('stock')->default(0);
    $table->foreignId('category_id')->constrained()->onDelete('cascade');
    $table->timestamps();
});
```

```bash
php artisan migrate
```
