Laravel incluye un sistema de [migraciones](https://laravel.com/docs/11.x/migrations) que funciona como **control de versiones para tu base de datos**. En lugar de modificar tablas a mano en SQL, defines la estructura con PHP, la compartes con tu equipo y puedes revertir cambios de forma segura.

:::tip[Recuerda]
Toda migración debe poder revertirse en el método `down()`. Si no puedes deshacer un cambio, no es una migración completa.
:::

## Ejemplo rápido

Lo primero que necesitas es crear el archivo de migración y definir la tabla:

```bash
php artisan make:migration create_posts_table
```

Esto genera un archivo en `database/migrations/` con una clase que tiene dos métodos: `up()` (para crear) y `down()` (para revertir). Dentro de `up()` defines la estructura. Por ejemplo, para una tabla de publicaciones (`posts`):

```php title="database/migrations/xxxx_create_posts_table.php"
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->text('content');
    $table->timestamps();
});
```

```bash
php artisan migrate
```

## Tipos de columna más usados

Blueprint ofrece muchos tipos de columna. Estos son los que usarás en la mayoría de tus tablas:

```php title="database/migrations/xxxx_create_products_table.php"
Schema::create('products', function (Blueprint $table) {
    $table->id();                          // Clave primaria autoincremental
    $table->string('name');                // VARCHAR(255)
    $table->string('sku')->unique();       // Con índice único
    $table->integer('stock');              // entero
    $table->boolean('is_active');          // true/false
    $table->decimal('price', 8, 2);        // Decimal con precisión
    $table->text('description');           // TEXT (largo)
    $table->foreignId('user_id')->constrained()->onDelete('cascade');
    $table->timestamps();                  // created_at + updated_at
    $table->softDeletes();
});
```

:::info[¿Qué genera esto?]
| Columna | Tipo en BD | Uso |
|---|---|---|
| `id` | `BIGINT UNSIGNED AUTO_INCREMENT` | Identificador único |
| `name` | `VARCHAR(255)` | Nombre del producto |
| `sku` | `VARCHAR(255) UNIQUE` | Código único |
| `price` | `DECIMAL(8,2)` | Precio con 2 decimales |
| `user_id` | `BIGINT UNSIGNED` | FK → `users.id` (autor) |
| `deleted_at` | `TIMESTAMP NULL` | Borrado lógico |
:::

Cuando estos no sean suficientes, Laravel ofrece más tipos especializados:

```php
$table->date('birthday');              // YYYY-MM-DD
$table->dateTime('published_at');      // Fecha y hora
$table->time('sunrise');               // Solo hora
$table->year('graduation_year');       // Solo año
$table->enum('status', ['active', 'inactive']); // Valores fijos
$table->json('options');               // JSON
$table->uuid('identifier');            // UUID v4
```

Para la [lista completa de tipos de columna](https://laravel.com/docs/11.x/migrations#available-column-types) disponibles, consulta la documentación oficial.

:::note[String con longitud personalizada]
Por defecto, `$table->string('name')` crea un `VARCHAR(255)`. Puedes reducirlo pasando la longitud como segundo argumento:
```php
$table->string('country_code', 3);  // VARCHAR(3)
```
:::

## Modificadores de columna

Los tipos de columna definen qué datos se almacenan, pero los [modificadores](https://laravel.com/docs/11.x/migrations#column-modifiers) controlan detalles como valores por defecto, nulabilidad y posición. Se encadenan al final de la definición del tipo:

```php title="database/migrations/xxxx_create_posts_table.php"
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('subtitle')->nullable();           // Permite NULL
    $table->boolean('published')->default(false);     // Valor por defecto
    $table->string('slug')->unique();                 // Índice único
    $table->decimal('revenue', 12, 2)->comment('Ingresos en local');
    $table->string('phone')->after('email');            // Posición (MySQL)
    $table->timestamps();
});
```

Los modificadores se pueden combinar libremente para ajustar el comportamiento de una columna:

```php
$table->string('email')
      ->unique()
      ->nullable()
      ->comment('Correo de contacto');
```

## Creación y actualización de tablas

Hasta ahora hemos usado `Schema::create` para crear tablas nuevas. Pero conforme tu aplicación evoluciona, también necesitarás modificar tablas existentes.

**Crear tabla** con el método [`create`](https://laravel.com/docs/11.x/migrations#creating-tables):

```php
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->text('content');
    $table->timestamps();
});
```

**Agregar columna a una tabla existente** con el método [`table`](https://laravel.com/docs/11.x/migrations#modifying-tables):

```php
Schema::table('users', function (Blueprint $table) {
    $table->string('phone')->nullable();
});
```

**Eliminar columna** de una tabla existente:

```php
Schema::table('users', function (Blueprint $table) {
    $table->dropColumn('phone');
});
```

**Renombrar tabla** sin perder datos:

```php
Schema::rename('customers', 'clients');
```

:::caution[Modificar columnas existentes]
Crear, agregar y eliminar columnas funciona directamente con Laravel. Pero para cambiar el tipo o renombrar una columna existente, necesitas instalar `doctrine/dbal`:
```bash
composer require doctrine/dbal
```
Consulta la [documentación sobre modificación de columnas](https://laravel.com/docs/11.x/migrations#modifying-columns) para más detalles.
:::

**Eliminar tabla** de forma segura (no lanza error si no existe):

```php
Schema::dropIfExists('posts');
```

## Índices

Los índices aceleran las consultas que filtran o buscan por ciertas columnas. Agregar índices a las columnas que uses frecuentemente en `WHERE`, `ORDER BY` o `JOIN` puede mejorar significativamente el rendimiento:

```php title="database/migrations/xxxx_add_indexes_to_users_table.php"
Schema::table('users', function (Blueprint $table) {
    $table->index('email');                          // Índice simple
    $table->index(['last_name', 'first_name']);      // Índice compuesto
    $table->unique('dni');                           // Índice único
    $table->fullText('biography');                   // Texto completo
});
```

Consulta la [documentación sobre índices](https://laravel.com/docs/11.x/migrations#indexes) para crear, nombrar y eliminar índices de forma manual.

## Claves foráneas

Las claves foráneas garantizan la integridad referencial entre tablas: impiden que se inserten valores huérfanos y definen qué pasa cuando un registro padre se elimina. Laravel ofrece una sintaxis moderna para definirlas:

```php
// Forma moderna (recomendada)
$table->foreignId('user_id')->constrained()->onDelete('cascade');

// Forma clásica
$table->unsignedBigInteger('user_id');
$table->foreign('user_id')->references('id')->on('users')->onDelete('cascade');
```

Con `constrained()`, Laravel deduce automáticamente la tabla y columna de referencia a partir del nombre de la columna (`user_id` → tabla `users`, columna `id`). Si tu convención no coincide, puedes especificar la tabla manualmente: `constrained('admins')`.

## Comandos de migración

Estos son los comandos que usarás a diario para gestionar el estado de tu base de datos:

| Comando | Descripción |
|---|---|
| `php artisan migrate` | Ejecuta migraciones pendientes |
| `php artisan migrate:rollback` | Revierte la última migración |
| `php artisan migrate:rollback --step=3` | Revierte las últimas 3 |
| `php artisan migrate:reset` | Revierte todas |
| `php artisan migrate:refresh` | Revierte y vuelve a ejecutar |
| `php artisan migrate:fresh` | Elimina tablas y re-ejecuta |
| `php artisan migrate:fresh --seed` | Fresh + ejecuta seeders |
| `php artisan migrate:status` | Muestra estado de cada migración |

Consulta la [documentación completa de comandos de migración](https://laravel.com/docs/11.x/migrations#artisan-commands) para más detalles.

## Convención de nombres

Laravel genera nombres de archivo automáticamente, pero si sigues estas convenciones, artisan creará la migración con la estructura correcta desde el inicio:

```bash
php artisan make:migration create_orders_table        # Crear tabla
php artisan make:migration add_status_to_orders_table  # Agregar columna
php artisan make:migration rename_total_to_amount      # Renombrar columna
php artisan make:migration remove_discount_from_orders # Eliminar columna
```
